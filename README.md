# brazilian-ecommerce-dashboard

## Overview
This project presents an interactive Tableau dashboard built using the Olist Brazilian E-Commerce dataset. The dashboard provides business insights related to sales performance, customer behavior, product categories, delivery efficiency, and payment analysis.

The goal of the project is to transform raw e-commerce data into clear and interactive visual analytics that support business decision-making.

---

## Dashboard Features
- Sales performance analysis
- Order status tracking
- Customer purchasing insights
- Product category analysis
- Payment method distribution
- Delivery performance monitoring
- Regional sales comparison

---

## Tools Used
- Tableau
- Data Visualization
- Business Intelligence Techniques

---

## Dataset
The dashboard is based on the Olist Brazilian E-Commerce dataset, which contains information about:
- Orders
- Customers
- Sellers
- Products
- Payments
- Reviews
